# Data

The data file is not stored in this repository.

Download `retail_price.csv` from the Kaggle dataset **Retail Price Optimization case study**
(https://www.kaggle.com/datasets/bhanupratapbiswas/retail-price-optimization-case-study) and put it in this folder as `data/retail_price.csv`.

It has 676 rows and 30 columns: 52 products in 9 categories, monthly from January 2017 to August 2018, with units sold (`qty`),
`unit_price`, freight price, competitor prices, product score, number of customers and calendar information
(`holiday` and `weekday` count the holidays and the weekdays of the month).
